`client_logged_out` is a stable SDK-local Latchway error code for Ios, Android, React Native.
It is not an HTTP Problem and has no canonical HTTP status or global
retryable value.

## What to do

This handle is terminal. After explicit account activation, create a new client even when signing back into the same account.
