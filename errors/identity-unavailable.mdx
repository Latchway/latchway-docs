`identity_unavailable` is a stable SDK-local Latchway error code for Ios, Android, React Native.
It is not an HTTP Problem and has no canonical HTTP status or global
retryable value.

## What to do

Restore the configured auth owner and obtain a consistent current-account snapshot. A missing JavaScript runtime must not authorize from cached credentials.
