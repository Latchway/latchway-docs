`client_disposed` is a stable SDK-local Latchway error code for Ios, Android, React Native.
It is not an HTTP Problem and has no canonical HTTP status or global
retryable value.

## What to do

Dispose releases one lease and is not logout. Use a live client or generation-scoped app logout for account cleanup.
