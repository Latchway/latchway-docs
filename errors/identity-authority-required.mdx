`identity_authority_required` is a stable SDK-local Latchway error code for Ios, Android, React Native.
It is not an HTTP Problem and has no canonical HTTP status or global
retryable value.

## What to do

Register one account-aware native or JavaScript identity owner before first configuration. A repeated configuration may omit that owner.
