`app_not_configured` is a stable SDK-local Latchway error code for Ios, Android, React Native.
It is not an HTTP Problem and has no canonical HTTP status or global
retryable value.

## What to do

Register the intended named native app before retrieving it. Do not fall back to another environment or identity owner.
