`crypto_unavailable` is a stable SDK-local Latchway error code for Javascript, React Native.
It is not an HTTP Problem and has no canonical HTTP status or global
retryable value.

## What to do

Use a supported runtime with the required P-256 signing and secure-random capabilities. Do not replace the installation key with an exportable application secret.

## Retry boundary

Honor the concrete error instance and SDK contract. Never infer that a
local transport failure happened before dispatch, and never replay a
consumed body or an operation with an indeterminate outcome.
