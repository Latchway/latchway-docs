`keychain_access_group_unavailable` is a stable SDK-local Latchway error code for Ios.
It is not an HTTP Problem and has no canonical HTTP status or global
retryable value.

## What to do

Add the required containing-app and extension Keychain Sharing entitlements, use the exact application-prefix-qualified group, and regenerate signing profiles before provisioning the component again.
