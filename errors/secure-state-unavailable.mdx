`secure_state_unavailable` is a stable SDK-local Latchway error code for Android.
It is not an HTTP Problem and has no canonical HTTP status or global
retryable value.

## What to do

Restore the configured Android secure-state and keystore capabilities before creating another session. Do not persist Latchway credentials in ordinary application storage.

## Retry boundary

Honor the concrete error instance and SDK contract. Never infer that a
local transport failure happened before dispatch, and never replay a
consumed body or an operation with an indeterminate outcome.
