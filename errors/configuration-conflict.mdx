`configuration_conflict` is a stable SDK-local Latchway error code for Ios, Android, React Native.
It is not an HTTP Problem and has no canonical HTTP status or global
retryable value.

## What to do

Reuse the registered app and its identity authority. Explicitly conflicting security or storage settings cannot replace an existing registration.

## Retry boundary

Honor the concrete error instance and SDK contract. Never infer that a
local transport failure happened before dispatch, and never replay a
consumed body or an operation with an indeterminate outcome.
