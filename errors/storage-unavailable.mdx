`storage_unavailable` is a stable SDK-local Latchway error code for Javascript, React Native.
It is not an HTTP Problem and has no canonical HTTP status or global
retryable value.

## What to do

Restore the platform storage capability required by the configured persistence mode, or choose an explicitly supported non-persistent mode when the application threat model permits it.
