## Outcome

Use the same TypeScript request surface on iOS and Android while native modules
own component keys, DPoP, session rotation, and platform attestation.

## Before you start

- a gateway application, environment, feature, identity, and platform trust
  configuration
- authorized, version-locked checkouts of the React Native, iOS, and Android
  SDK source candidates
- React Native 0.82 with the New Architecture enabled
- iOS 15+ and Android API 24+ native toolchains

<Warning>
  The npm package and native artifacts are not published. The source example is
  the prepublication integration path. Current evidence covers React Native
  commit `6de46e1c7264e1d45cdd31174e4ea040a8c24acf` on a real iPad running
  iPadOS 26.5 in Debug configuration with automatic Apple Development signing.
  Current source `af3860cbf39ab6a8d1d76da392cb699b9e019e42` passes the full
  local suite plus generic iOS and isolated Debug/Release App Intent build gates
  and adds a Debug native delegated-request path, but that intent has not yet
  been physically invoked. Android physical, protected extension-matrix, and
  protected distribution evidence remain release gates.
</Warning>

## What you will build

```text
TypeScript API -> native iOS or Android module -> platform key + attestation -> Latchway
```

JavaScript never receives a private key, attestation evidence, access token, or
refresh token from the native bridge.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The native module is unavailable">
    Confirm React Native 0.82 New Architecture, install CocoaPods on iOS, clean
    the Android build, and rebuild the host application. Expo support is not
    inferred from the source candidate.
  </Accordion>
  <Accordion title="Two clients report conflicting configuration">
    Equivalent clients share one native security scope. Create one stable
    client per scope and keep its gateway, application, environment, and native
    security configuration identical.
  </Accordion>
  <Accordion title="Streaming stops after cancellation">
    Cancellation is terminal for that request. Create a new request; never
    replay a consumed or streaming body to recover a session.
  </Accordion>
</AccordionGroup>

<Prompt title="Integrate Latchway React Native source candidate 1.0.0">
Use React Native SDK 1.0.0 with React Native 0.82 New Architecture and server

streaming, and never expose native credentials or provider keys to JavaScript.
