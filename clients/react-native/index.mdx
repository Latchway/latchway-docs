The React Native API is TypeScript, but the security boundary is native. The
iOS or Android module owns the component key, App Attest or Play Integrity,
DPoP signing, rotating refresh state, and protected network request.

React Native can configure first, whether it owns the whole app or one embedded
screen. Matching native configuration later reuses that same app and account;
the reverse order works too. Supply tokens from your existing authentication
flow. Latchway imports no Firebase module and requires no native auth bootstrap.

## Runtime boundary

```text
TypeScript API -> TurboModule -> native iOS or Android SDK -> Latchway
                   no keys, proofs, sessions, or raw attestation returned
```

- [Authentication](/clients/react-native/authentication) covers supplied tokens,
  same-account refresh, shared logout and account-change cancellation.
- [Send a request](/clients/react-native/send-a-request) covers the bounded
  feature-aware fetch surface.
- [Streaming](/clients/react-native/streaming) covers pull-driven responses and
  `AbortSignal` cancellation.
- [Framework integrations](/clients/react-native/framework-integrations)

- [App extensions](/clients/react-native/app-extensions) records the current

  operation IDs safe across the bridge.

## Support boundary

The 1.2 release line accepts React Native `>=0.74.0 <1.0.0` and React
`^18.2.0 || ^19.0.0` with the New Architecture, iOS 15+, and Android API 24+.
The host must use a compatible React/React Native pair; a peer range is not
verification of every future release. Shared supplied identity requires
server 1.1.1 and compatible native SDKs. Legacy Architecture and Expo-managed
support are not inferred. See [Release status](/release-status) for available
packages and remaining evidence limits. Consult the generated
[React Native SDK bundle](/reference/sdk-bundles/react-native) for exact source
and version evidence.

<Warning>
  React Native and Web share JavaScript syntax but not a trust model. Do not
  replace the native module with WebCrypto, IndexedDB, App Check, Turnstile, or
  a browser client inside a native application.
</Warning>
