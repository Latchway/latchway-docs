## Request path

```text
existing identity -> Play Integrity-aware session -> Keystore DPoP -> feature policy -> upstream
```

- [Authentication](/clients/android/authentication) defines the current-user
  token callback independently from integrity.
- [OkHttp](/clients/android/okhttp) installs the application interceptor,
  network origin guard, and bounded authenticator.
- [Retrofit](/clients/android/retrofit) reuses that hardened client without
  duplicating session logic.
- [Streaming](/clients/android/streaming) covers incremental response bodies
  and cancellation.
- [Background execution](/clients/android/background-execution) covers
  lifecycle and work constraints without moving secrets into job input.
- [Error handling](/clients/android/error-handling) starts from stable codes and
  safe request IDs.

## Support boundary

The native libraries support Android API 23 or newer. The React Native bridge
requires API 24 or newer. The intended Maven coordinates remain unpublished
until [Release status](/release-status) records promotion. Use the generated
[Android SDK bundle](/reference/sdk-bundles/android) for source-provenanced
version and example evidence.

<Warning>
  A fixture, emulator, or sideloaded APK does not establish a production Play
  Integrity verdict. The final trust gate requires the exact signed application
  installed through the configured Google Play track.
</Warning>
