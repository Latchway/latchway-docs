The browser SDK is a first-class Latchway client. It creates a non-exportable
P-256 key with WebCrypto, stores the key object and rotating session state in
IndexedDB, binds every protected request with DPoP, and preserves Fetch
streaming and cancellation.

<Warning>
  WebCrypto key possession and App Check or Turnstile are browser risk
  controls. They are not Secure Enclave, Android Keystore, App Attest, or Play
  Integrity equivalents. Same-origin JavaScript can invoke the key.
</Warning>

## Runtime boundary

```text
Browser user identity
        +
non-exportable WebCrypto component key
        +
optional required App Check or Turnstile challenge evidence
        |
        v
exact-origin, feature-bound Fetch -> Latchway policy, quota, and routing
```

Use [Browser versus Node.js](/clients/web/browser-vs-node) before importing the
package in a hybrid runtime. Node conformance mode uses a memory-only software
key and does not inherit browser trust.
