Initialize Firebase App Check in application code using Firebase's supported
Web provider, then pass only its official `getToken` callback to Latchway:

```typescript
import {
  createFirebaseAppCheckProvider,
  createFirebaseIdentityTokenProvider,
} from "@latchway/client/firebase";

const latchway = createLatchwayClient({
  baseURL: "https://ai.example.com",
  applicationID: "app_01J00000000000000000000000",
  environment: "production",
  identityProvider: "firebase",
  identityTokenProvider: createFirebaseIdentityTokenProvider(
    () => auth.currentUser!.getIdToken(),
  ),
  attestationProviders: [createFirebaseAppCheckProvider(
    (forceRefresh) => getToken(appCheck, forceRefresh),
  )],
});
```

The adapter requests a fresh token during a Latchway challenge. Latchway sends
that opaque value to the server-side verifier. Refresh contains no identity or
App Check token; a step-up starts a new challenge flow.

environment. Never enable a debug token or debug verifier in production.
