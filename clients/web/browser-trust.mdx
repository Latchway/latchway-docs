Browser trust is a layered risk decision, not native physical-device
attestation.

<BrowserTrustStack />

Use identity to identify the user. Use the WebCrypto key to bind a component
session. Configure Firebase App Check or Turnstile when server policy needs an
additional application or abuse-risk signal. Restrict exact origins, reduce
script injection with CSP, and keep feature and quota decisions on the server.
