The widget action must equal the server-configured action. Its `cData` must
equal `challenge.attestation.client_data_hash` exactly:

```typescript
import { createTurnstileProvider } from "@latchway/client/turnstile";

const turnstile = createTurnstileProvider({
  action: "latchway_session",
  getToken: ({ challenge }) => runTurnstileForChallenge({
    action: "latchway_session",
    cData: challenge.attestation.client_data_hash,
  }),
});
```

Execute the widget once for each server challenge. Do not reuse evidence, attach
it to ordinary requests, or add it to refresh. Latchway verifies the returned
action and binding through Siteverify and rejects a mismatch.
