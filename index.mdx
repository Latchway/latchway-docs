Latchway is a self-hosted access gateway for iOS, Android, Web, and React
Native applications. It authenticates users, evaluates platform trust, binds
short-lived sessions to component keys, applies server-owned feature policy and
limits, and selects the upstream route without returning provider credentials
to the client.

<Warning>
  Version 1.0.0 is a tested source candidate. Public packages, final tags,
  immutable release assets, and protected production evidence remain release
  gates. Source-mode instructions on this site identify that boundary.
</Warning>

The application may select a configured feature and send supported request
content. It cannot select a trusted user, physical model, route, price, or
usage result.
