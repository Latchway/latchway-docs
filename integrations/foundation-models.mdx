## 1. What this integration does

The source Class B adapter implements the Apple Foundation Models custom
executor interfaces and uses an existing Latchway transport. It does not
introduce a parallel chat, prompt, tool, transcript, or model framework.

## 2. Supported framework versions

The released registry records one experimental source tuple: Apple Foundation
Models `27.0.0` through `27.0.0`. Its immutable `1.0.0` snapshot records nine
simulator tests covering text, transcript, incremental usage, cancellation,
quota and unavailable mapping, refresh, and explicit tool and schema rejection.
Twelve iOS 27.0 simulator tests now pass in current source; the three later cases
cover header isolation, provider-placeholder isolation, and logger redaction.
Those post-freeze cases strengthen local evidence without widening the released
range.

## 3. Supported Latchway versions

The tested source tuple uses Latchway Swift SDK `1.0.0` and server contract
`1.0.0`. Neither coordinate is a published supported adapter release.

## 11. Use tools

Tools are not supported by this exact tuple. The adapter rejects them rather
than silently dropping their semantics. Latchway does not execute tools.

## 12. Use structured output

Generated schemas and structured output are not supported by this exact tuple.
The adapter rejects them explicitly.

## 13. Handle cancellation

The exact simulator suite proves that task cancellation reaches the active
transport and does not replay work.

## 14. Handle quota failures

Map a canonical quota problem into an explicit framework error while retaining

## 15. Handle session renewal

The Swift transport owns single-flight refresh and exact pre-dispatch retry
rules; framework code never receives refresh credentials.

## 16. Known limitations

Tools, generated schemas, Chat Completions, embeddings, audio, and images are
not supported. Physical framework execution, delegated-extension runtime,
published artifacts, and versions outside exact 27.0.0 remain unverified.

## 17. Verify the integration

From the authorized iOS SDK checkout, run
`swift test --filter LatchwayFoundationModelsTests`. A passing result proves the
exact simulator source cases only; compare the generated
[Compatibility matrix](/reference/compatibility) before making a support claim.

## 18. Troubleshooting

Check platform availability, declared capabilities, feature policy, and safe
transport diagnostics before treating a translation error as a server failure.
