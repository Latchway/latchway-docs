SDK quickstarts and framework examples are imported only through
`scripts/docs-sync-sdk`. Every generated source file identifies the SDK repository,
documented SDK version, documentation source commit, file, and exact line region.
The validator checks the archive, manifest, checksums, lock, provenance, and generated output.

A documentation-only follow-up may have a newer source commit than the immutable SDK
release tag. Source links use the recorded documentation commit, not an assumed tag target.

<Warning>
  A checked-in source bundle is not evidence that its registry package or GitHub
  release is public. See [Release status](/release-status) for protected external gates.
</Warning>

## Update a bundle

Run the source repository's bundle producer, then import the exact coordinate:

```shell
scripts/docs-sync-sdk android 1.2.1
scripts/docs-sync-sdk ios 2.0.0
scripts/docs-sync-sdk js 1.1.0
scripts/docs-sync-sdk react-native 2.0.0
```

The command rejects archive traversal, links, non-canonical metadata, unknown files,
checksum or manifest drift, source hash drift, and a commit that differs from the
checked-out SDK repository. `scripts/docs-sync-sdk --check` is read-only.
