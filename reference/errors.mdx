Latchway returns `application/problem+json`. The registry currently
defines 59 stable codes. Provider payloads, credentials,
identity tokens, proofs, and raw internal errors are excluded.

## Problem fields

| Class | Fields |
| --- | --- |
| Required | `type`, `title`, `status`, `detail`, `code`, `request_id`, `retryable` |
| Optional | `instance`, `retry_after`, `operation_id`, `feature`, `supported_protocol_versions`, `errors` |

`operation_id` is required only for `operation_indeterminate` and is forbidden for every other code.

<Warning>
  `retryable: true` does not authorize a blind replay. Respect
  `retry_after`, the SDK's pre-dispatch boundary, and the route/session
  contract. Reconcile indeterminate mutations from durable state.
</Warning>
