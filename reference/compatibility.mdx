## Current limitations

- **Android OkHttp ecosystem (`android-okhttp`):** Local source, route, replay, streaming, and cancellation tests pass on 4.9.2 and 5.3.0; hosted gateway conformance and physical Play-distributed key proof remain release gates.
- **Apple Foundation Models (`foundation-models`):** Nine iOS 27.0 simulator tests pass text, transcript, incremental usage, cancellation, quota/unavailable mapping, refresh, and explicit tools/schema rejection; physical framework execution and delegated-extension runtime remain pending.
- **Koog OpenAI client (`koog-android`):** Full local Koog 1.1.1 conformance passes only with OkHttp/okhttp-sse 5.3.0, explicit utils-jvm 1.1.1, Kotlin Logging 8.0.01, and an absolute chat path; 4.9.2 passes the four non-streaming cases but is incompatible with Koog SSE. Hosted gateway, live-provider, physical Play-distributed key, exact-image, and versions beyond the exact tested tuple remain release gates.
- **LangChain JavaScript (`langchain-js`):** Local @langchain/openai 1.5.10 case-ID tests pass Chat, embeddings, streaming usage, tools, structured output, cancellation, error mapping, retry/refresh, and transport security; hosted/exact-image, live-provider, and revocation evidence remain release gates.
- **MacPaw OpenAI (`macpaw-openai`):** Published MacPaw/OpenAI 0.5.1 lacks async request middleware and public streaming injection, so no adapter ships; a repository patch adding ordered async interception passes all 217 upstream tests but has not been accepted or released upstream.
- **OpenAI JavaScript SDK (`openai-js`):** Local OpenAI 7.8.0 case-ID tests pass Responses, Chat, embeddings, Responses/Chat streaming usage, tools, structured output, cancellation, error mapping, retry/refresh, and transport security; media, hosted/exact-image, live-provider, and revocation evidence remain release gates.
- **React Native framework fetch (`react-native-fetch`):** React Native 0.82.0 New Architecture local gates pass. A real iPad running iPadOS 26.5 built commit 6de46e1c7264e1d45cdd31174e4ea040a8c24acf in Debug configuration with automatic Apple Development signing. That development run proved production App Attest registration and same-key assertion, Secure Enclave DPoP, gateway traffic, quota, typed component denial, bridge behavior, and cleanup. Android, delegated-extension runtime, and protected Apple distribution-derived exact-candidate evidence remain pending.
- **SwiftOpenAI (`swift-openai`):** Buffered and line-stream HTTP pass exact SwiftOpenAI 4.6.0 tests; WebSocket Realtime bypasses the injectable HTTP client and is unsupported, while physical cancellation proof is pending.
- **Vercel AI SDK (`vercel-ai-sdk`):** Local AI SDK 7.0.85/@ai-sdk/openai 4.0.52 case-ID tests pass Responses, Chat, embeddings, both streams, tools, typed output, cancellation, errors, retry/refresh, and transport security; images, hosted/exact-image, live-provider, and revocation evidence remain release gates.

## Evidence required for support

A supported tuple names the framework and adapter versions, Latchway
SDK/platform and server range, contract/wire coordinate, integration
class, security level, capabilities, limitations, and exact conformance
evidence. Minimum and latest declared versions must pass, and scheduled
newest-compatible failures open an issue without widening the range.

See [Release status](/release-status) for source and publication blockers.
