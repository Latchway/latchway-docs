## Current limitations

- **Android OkHttp ecosystem (`android-okhttp`):** Local source, route, replay, streaming, cancellation, and OkHttp 5.3.0 tests pass; hosted gateway conformance and physical Play-distributed key proof remain release gates.
- **Apple Foundation Models (`foundation-models`):** The OS 27 custom executor compiles, but its runtime tests were skipped on an older host OS; gateway and physical-device execution remain pending.
- **LangChain JavaScript (`langchain-js`):** Chat and embeddings pass local adapter tests at @langchain/openai 1.5.10; streaming/tool paths and hosted common conformance are not yet release evidence.
- **MacPaw OpenAI (`macpaw-openai`):** MacPaw/OpenAI 0.5.1 exposes only synchronous request middleware and no public streaming transport injection, so a safe transparent Latchway adapter cannot be shipped.
- **OpenAI JavaScript SDK (`openai-js`):** Responses plus chat streaming/cancellation pass local OpenAI 7.8.0 adapter tests; tools, media, embeddings, and hosted common conformance remain conditional.
- **React Native framework fetch (`react-native-fetch`):** React Native 0.82.0 New Architecture hosts, native-only credentials, pull streaming and cancellation pass local gates; live gateway and physical iOS/Android proof remain pending.
- **SwiftOpenAI (`swift-openai`):** Buffered and line-stream HTTP pass exact SwiftOpenAI 4.6.0 tests; WebSocket Realtime bypasses the injectable HTTP client and is unsupported, while physical cancellation proof is pending.
- **Vercel AI SDK (`vercel-ai-sdk`):** Responses, chat, embeddings, streaming and cancellation pass local AI SDK 7.0.85 adapter tests; tools, images and hosted common conformance remain conditional.

## Evidence required for support

A supported tuple names the framework and adapter versions, Latchway
SDK/platform and server range, contract/wire coordinate, integration
class, security level, capabilities, limitations, and exact conformance
evidence. Minimum and latest declared versions must pass, and scheduled
newest-compatible failures open an issue without widening the range.
